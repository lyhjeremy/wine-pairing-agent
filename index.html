A LangGraph agent with retrieval as a tool

Name a dish. It picks the style, finds the bottles, then checks itself.

The agent reasons from pairing principles to a wine style, searches real Wine Enthusiast reviews with your budget as a filter, recommends one or two bottles with citations, and goes back to re-strategize if its own critique finds a problem.

Critique: sound. Every bottle, score and price comes from a retrieved review.

What each node does

  1. parse turns the meal into JSON: main ingredient, body, sauce, cuisine, flavors, cooking method.
  2. strategize applies the principles in src/pairing.py (acid cuts fat, tannin binds protein, match weight, sweetness tames heat) to choose a style and write a search query.
  3. retrieve calls search_wines, a LangChain StructuredTool over a local Chroma index, with the budget as a price filter.
  4. recommend has Claude pick from the retrieved wines only and cite each as [n].
  5. critique checks for at least two candidates and one within budget, then asks an LLM whether the pairing is coherent.

Traced

--trace times each node and saves the run as JSON. In one traced ribeye run the local search took 0.3 seconds and the four LLM steps took 1.2 to 3.0 seconds each.

Limits

Pairing quality is not scored against a benchmark, so this shows a working, self-checking agent, not a measured one. The principles are a short list, retrieval filters on price only, and the default index holds the 30,000 highest-scored reviews.
